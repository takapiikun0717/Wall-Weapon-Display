## Description
Add multiple weapon displays
## Installation instructions
Place the WallWeaponDisplay.vmz file in the ‘mods’ folder and launch the game
Main features
There’s only one type of Vanilla weapon display, and as it’s the kind you place on the floor, I found it a bit awkward to use, so I created this mod.
I’ve added three new types of wall-mounted weapon displays—two large and one small of each type.
* Panels
* Pegboards (gray, black)

You can purchase each display from the Gunsmith.
Generalists can purchase various types of smaller displays.

Key Hook added in version 1.10.0
Available for purchase from Generalist

* Key Hooks (Wooden, Metal)

## Requirements
Metro Mod Loader  ver3.4.2 or later
